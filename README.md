# 🛍️ NOVA STORE — Premium Online Shopping

NOVA STORE is a fully responsive, front-end e-commerce website built with vanilla HTML, CSS, and JavaScript. It simulates a complete online shopping experience including product browsing, cart management, coupon system, and a demo checkout process.

## 🚀 Features

- **Fully Responsive Design:** Works perfectly on Desktop, Tablet, and Mobile devices.
- **Single Page Application (SPA) Feel:** Uses Hash-based routing (`#home`, `#shop`, `#cart`) for smooth page transitions without reloading.
- **Product Catalog:** Browse products by categories (Electronics, Fashion, Accessories, Home & Living).
- **Search & Filter:** Search products by name/category and filter by price range and sorting.
- **Wishlist:** Users can like/save their favorite products.
- **Shopping Cart:** Add, remove, and adjust product quantities. Includes a dynamic subtotal, shipping cost, and coupon discount system.
- **Coupon Codes:** Includes a working coupon system.
  - `NOVA10` (10% Off)
  - `WELCOME5` ($5 Off)
  - `SAVE20` (20% Off)
- **Checkout Form:** A beautiful checkout page with form validation (Name, Email, Address, etc.).
- **Payment Methods:** Demo checkout supports Cash on Delivery (COD) and Credit/Debit Card (UI only).
- **Order Success:** Placing an order generates a random Order ID, clears the cart, and shows a success message.
- **Modern UI/UX:** Built with CSS Flexbox, Grid, and Glassmorphism effects.
- **Icons:** Uses **Flaticon** (uicons) and **Lucide** for beautiful icons.

## 🛠️ Technologies Used

- **HTML5:** Semantic structure.
- **CSS3:** Custom properties (variables), Flexbox, CSS Grid, Animations, and Media Queries.
- **JavaScript (ES6):** DOM manipulation, Local Storage (for Cart & Wishlist), Event delegation, and Hash routing.
- **Fonts:** Google Fonts (Inter).
- **Icons:** Flaticon (UIcons) & Lucide Icons.
